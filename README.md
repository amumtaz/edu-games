# edu-games

This repository contains simple educational games built using the `pygame` library. Each game focuses on helping kids learn or practice a particular skill in a fun way.

## Games

### Guess the Flag
A timed multiple-choice quiz where players identify country flags as quickly as possible. The game uses emoji-based flag images from the `emoji-flags` Python package so no additional assets are required. Players have 60 seconds to score as many correct answers as they can.

More games will be added over time. Please provide feedback on how to improve these games and we will incorporate the suggestions.
